# Hi, I'm John

I'm an Electrical and Computer Engineering and Statistics and Data Science student at the University of Arizona interested in FPGA design, embedded systems, computer architecture, and hardware acceleration.

A lot of my work revolves around one question:

> How can we move computation closer to the hardware and make systems faster, more efficient, and more capable?

I enjoy building systems that cross the boundary between software and hardware, from writing C++ and HLS acceleration kernels to integrating FPGA IP, embedded processors, sensors, communication interfaces, and machine learning models into complete systems.

## What I'm Working On

### FPGA Accelerated Computer Vision

I'm currently exploring hardware acceleration for computer vision and machine learning workloads using AMD and Xilinx FPGAs and SoCs.

One of my recent projects is a complete FPGA accelerated human detection system:

Camera -> Raspberry Pi Zero 2 W -> ESP32 -> FPGA -> HOG Feature Extraction -> SVM Inference -> Embedded Control

The project started as an HLS based HOG accelerator and evolved into a live embedded vision pipeline with custom communication logic and FPGA based inference.

Project: [FPGA Accelerated Human Detection](https://github.com/johnrott/FPGA-Accelerated-Human-Detection)

## Hardware Acceleration and Reconfigurable Computing
